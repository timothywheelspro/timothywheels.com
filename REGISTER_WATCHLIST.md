# Register Watchlist

Run this checklist before committing any change to a destination page.

---

## Four Criteria

**1. Topology Continuity**
- [ ] Routing logic present (routing, boundaries, cost-of-change, drift detection)
- [ ] Page reinforces the same topology signal as Leadership/About

**2. Register Consistency**
- [ ] Would this paragraph print beside Leadership without tonal seam?
- [ ] No motivational cadence, no developmental framing, no explainer-overload

**3. Terminology Discipline**
Canonical terms: Layer 0, clarity infrastructure, routing logic, cost-of-change,
boundary enforcement, orchestration, deterministic pathways, protocol surface
- [ ] No substitution with: framework, method, guide, philosophy (as replacements)
- [ ] No marketing cadence ("Discover why…", "use this when…")

**4. No Resume Drift**
- [ ] No timeline anchors (dates, "three weeks into…", anniversaries)
- [ ] No achievement stacking
- [ ] No autobiographical opener
- [ ] No first-person origin story

---

## Change Control Rule

Any change to a destination page triggers:
- [ ] Re-check Home nav description that points to it
- [ ] Re-check any cross-links that summarize it
- [ ] Re-run all four criteria above on the changed file

---

## Placeholder Activation Gate

A draft page goes live only when it passes all of the following:

- [ ] Defined scope (one sentence, what the page covers)
- [ ] Stable thesis line (one sentence, what the page argues or demonstrates)
- [ ] No autobiographical opener
- [ ] At least one protocol-anchored term tied back to site topology
- [ ] Passes all four Register criteria above
